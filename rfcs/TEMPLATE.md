# Short proposal title

Ticket: [IGNITE-NNNNN](https://issues.apache.org/jira/browse/IGNITE-NNNNN)

## Problem

What problem does this solve, and who is affected?

## Proposed change

Describe what will change. For API or behavior changes, show a small usage example or a before/after comparison.

Explain why this approach was chosen. Compare other realistic options where relevant.

## Compatibility and migration

Name the affected clients and versions. Explain what changes for existing applications, configurations, integrations, or stored data.

State whether the change is compatible and explain why. For a breaking change, describe the steps users must take and the deprecation and migration plan.

If you propose skipping deprecation, say so. Explain the reason, expected impact, and supporting evidence. Having no known users is not enough.

## Implementation and checks

Link all implementation tickets. List the work and tests or other checks needed to consider the work complete. Include checks for the proposed behavior and compatibility.
